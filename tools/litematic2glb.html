🏛 Litematic → 白模 GLB 转换器

把玩家用 Litematica 采集的 .litematic 文件转换成 3D 城市沙盘白模，全程浏览器本地处理，文件不上传服务器。支持多文件合并。

③ 区块导出结果（渐进加载沙盘）

⬇️ 下载 manifest.json
把 manifest.json 与全部 chunk_*.glb 一起放进网站 models/chunks/ 目录即可。map.html 会从最接近中心的区块开始，相邻区块依次上浮直至铺满全图；互不相连的区域自动多点起涟。POST 需先运行 tools/serve.ps1（http://127.0.0.1:8931），保存后打开 /map.html 验证。

📖 玩家采集指引（转发给采城的玩家）

Litematica 采集步骤（Fabric 客户端）
  1. 安装 Fabric Loader + Fabric API + Litematica（Modrinth 搜 Litematica，注意匹配游戏版本）
  2. 进服后按 M 打开 Litematica 菜单 → Area Selection（区域选择）
  3. Create New Selection 新建选区，创建一个 Selection Box，把整座城市框进去（Y 从地面以下几格到建筑最高点）
  4. 角点可以直接在菜单里填坐标，也可以绑定热键 Add selection box corner 1/2 后到现场按热键定点
  5. 注意：只有加载过的区块才能被保存，框选前先绕城飞一圈让区块加载
  6. 回菜单点 Save Schematic 保存，文件在 .minecraft/schematic/ 目录，发给你即可
  7. 城市太大单个选区存不下时：分几块采（如东城/西城），多个文件本工具会自动合并
说明：草木、花朵、旗帜、告示牌、按钮、画、盆栽等装饰方块会自动剔除（不进模型）；玻璃渲染为半透明白，水渲染为浅蓝半透明； 被玻璃/水遮挡的墙体、地面等实心面依然渲染；半砖按半格高度、楼梯按半板+朝向侧板、栅栏按立柱+横杆、门按开合薄板（保留采集时的开/关状态）、活板门按水平薄板（开启时翻起竖立）近似渲染（石砖等整块材料按实心处理）。 贴着选区边界的方块外立面完整保留。 转换会自动剔除建筑物内部看不见的方块，只保留外表面，所以体积可控。除整体单模型外，还支持分区块导出（每区域一个 GLB + manifest.json），地图页会涟漪式逐块上浮加载。
