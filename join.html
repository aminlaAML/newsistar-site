开启你的旅程

跟随以下步骤，几分钟内即可加入 NewSistar 国

🚀 加入步骤

安装 Minecraft Java 版

需要正版 Minecraft Java 版，版本 1.21.4。可在 Minecraft 官网 购买。

安装 Fabric 加载器

前往 Fabric 官网 下载安装器，选择版本 1.21.4，运行安装。

下载必备 Mod

访问服务器页面，下载所有必装 mod，放入 .minecraft/mods 目录。

添加服务器

启动游戏 → 多人游戏 → 添加服务器，地址填写：

play.newsistar.com

加入社区

加入我们的 QQ 群 / Discord，获取最新资讯、参与活动、寻求帮助。

开始游戏

双击服务器进入，/spawn 回到出生点，/help 查看指令帮助。祝你游戏愉快！

❓ 常见问题

能否离线/盗版加入？
本服仅支持正版 Java 版账户，离线模式无法加入。
能否手机/基岩版加入？
暂不支持，本服仅 Java 版。
是否收费？
服务器永久免费，不售卖任何道具或权限。
数据会丢失吗？
服务器定期自动备份，存档数据安全可靠。
如何申请管理职位？
联系服主，满足一定条件可申请审核员/管理员。
